📼 ARCHIVE TV — How It Works

Archive TV functions as a virtual broadcast cable headend. Videos run on a synchronized global clock—meaning every viewer tuning into a channel sees the exact same moment of the broadcast!

📺 Adding Custom Channels

Channels are configured in channels.json. You can paste Internet Archive identifiers or YouTube links. 

{
  "name": "Classic Retro Cartoons",
  "mode": "loop",        // "loop" repeats items all day, "fixed" locks to exact times
  "start": "07:00",      // Broadcast cycle start time
  "color": "#38bdf8",    // Guide row accent color
  "items": [
    { "id": "popeye_patriotic_popeye" },
    { "id": "yt:v9EdW9ADEZQ" }
  ]
}

🍿 Commercial Breaks & Mid-Cut Resume

Archive TV supports mid-episode commercial interruptions. Define a break pool in commercials.json and episodes will cut out, play retro ads, and resume at the precise video frame where it cut off!
