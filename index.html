Creating channels

Channels live in channels.json next to this page. Click ＋ New channel in the top bar: paste archive.org video URLs or identifiers, hit Build, copy the JSON, and paste it into the "channels" list in channels.json. Save the file and refresh — that's it.

Manual editing

The id is the piece in the address bar: https://archive.org/details/his_girl_friday → "id": "his_girl_friday". Video lengths are fetched automatically from archive.org, so a channel can be as simple as: 

{
  "name": "My Channel",
  "mode": "loop",        // videos repeat in order, all day
  "start": "07:00",      // time the loop begins
  "color": "#38bdf8",    // row color in the guide
  "items": [
    { "id": "popeye_patriotic_popeye" },
    { "id": "house_on_haunted_hill_ipod", "seconds": 5400 }
  ]
}

Use "mode": "fixed" and give each item a "time": "20:30" to pin programs to exact broadcast times. Use "seconds" (or "minutes") only if a video's length can't be auto-detected.

Tips

  • Click any program in the guide to watch it in the player at the bottom.
  • Click a channel's name in the guide to jump to its day list.
  • Switch between Guide / Day List / Now Playing any time — the site remembers your last view.

Owner controls

Channel creation is owner-only. In channels.json set "ownerPassword": "your-secret" — the ＋ New channel button then asks for the passcode. Visitors who don't know it can watch the guide and play videos but can never create channels. When the site is published, real protection comes from hosting: channels.json lives where only you can change it (e.g. your GitHub repo), so viewers see exactly the channels you created — and nothing else.

Real broadcast times

Programs run on the clock. Clicking a program that's on-air right now joins it at the actual broadcast position (the player seeks there), and while a live channel is open it advances automatically to the next program when one ends — just like real TV. So every visitor is on the same broadcast clock no matter where they live, set "timezone": "utc" in channels.json.

Sharing with everyone

Quickest: Netlify Drop

  1. Go to app.netlify.com/drop.
  2. Drag this whole archive-tv folder onto the page.
  3. You get a public link like https://your-name.netlify.app — anyone can visit and see your channels.

Classic: GitHub Pages

  1. Create a GitHub repository and upload these files (not serve.bat).
  2. Settings → Pages → Source: main branch.
  3. Your site: https://you.github.io/your-repo.

Updating channels later = edit channels.json (or build one here, copy the JSON in) and re-upload just that file. Only people with access to your repo/hosting can do that — your viewers can't.
